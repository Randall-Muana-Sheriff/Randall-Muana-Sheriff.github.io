A direct connection from farm to market.

A web-based agricultural marketplace connecting farmers with customers, with a focus on market access, direct trade, and price transparency.

ReactNode.jsPostgreSQL
View repository ↗
Inside the project +
The problem

Smallholder farmers need better access to customers and clearer market information. FarmLink explores how an online marketplace can support these connections.

My contribution

Translated the problem into software requirements, built the React frontend and Node.js backend, and designed persistent data storage with PostgreSQL. Applied testing, debugging, verification, and validation throughout development.

Project stage

The application has been implemented as my final-year project. Dissertation work and preparation for the project defence are ongoing.
